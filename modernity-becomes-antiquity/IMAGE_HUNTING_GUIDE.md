## Image Requirements

- **Format**: JPG, PNG, or GIF (GIF for animated memes like Nyan Cat)
- **Size**: Ideally 400-600px wide, but any size will work (the CSS will scale it)
- **Naming**: Use lowercase, no spaces (use underscores if needed)
- **Quality**: Clear, recognizable versions of the memes

## Where to Find Them

1. **Google Images**: Search for "[meme name] meme" and look for high-quality versions
2. **Know Your Meme**: https://knowyourmeme.com - Each meme page usually has the original image
3. **Imgur**: https://imgur.com - Search for the meme name
4. **Wikipedia**: Some memes have their own Wikipedia pages with images
5. **Reddit**: Search r/memes or r/OutOfTheLoop for clean versions

## Current Setup

The HTML file currently has 9 meme entries that reference images. Once you add the image files to the `images/` folder, update the image paths in the `sources` array from:

```javascript
image: "https://picsum.photos/seed/nyancat/400/300"
```

To:

```javascript
image: "images/nyancat.gif"
```

## Tips for Hunting

1. **Use reverse image search** to find the highest quality version
2. **Check the original source** - KnowYourMeme often has the original image
3. **Avoid watermarks** - Try to find clean versions without logos or text overlays
4. **For animated memes** (like Nyan Cat), make sure to get the GIF version
5. **Test locally** - Add a few images and test the page locally before committing

Happy hunting, digital archaeologist! 🏺
